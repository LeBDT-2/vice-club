# Avatars tout prêts : les 20 portraits à générer

Génère chaque image dans ChatGPT (ou un autre générateur d’images), **une conversation par image**. Copie le texte du bloc tel quel.

Enregistre chaque image avec le nom indiqué (par exemple `m01.png`), toutes dans le même dossier. Ensuite, dans PowerShell :

```
cd C:\Users\morea\Documents\vice-club
git pull
pnpm.cmd import:avatars C:\chemin\vers\ton\dossier
```

Si un portrait ne te plaît pas, régénère-le avant de l’importer. Si le visage ressemble à une vraie personne célèbre ou à un personnage de GTA, régénère-le aussi.
